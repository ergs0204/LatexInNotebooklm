# Code Of Conduct

## Our Standards

We want participation in this project to be a respectful and productive experience for everyone.

Examples of positive behavior include:

- Giving and accepting constructive technical feedback
- Respecting different experience levels and viewpoints
- Focusing discussion on the project and the problem being solved
- Protecting other people's privacy and sensitive information

Unacceptable behavior includes harassment, personal attacks, discriminatory language, deliberate disruption, publishing private information, or any conduct that would reasonably make others feel unsafe or unwelcome.

## Scope

This code applies in repository issues, pull requests, reviews, discussions, and other public spaces where someone is representing this project.

## Enforcement

Report unacceptable behavior privately to `ergs0204@gmail.com`. Reports will be reviewed fairly and kept confidential where practical. The maintainer may edit or remove content, reject contributions, issue warnings, or temporarily or permanently restrict participation when necessary.

Project maintainers are responsible for clarifying and enforcing these standards consistently.
