# Security Policy

## Reporting A Vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the maintainer through the email listed on the GitHub profile.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not include credentials, private NotebookLM content, or other sensitive data.

Security reports will be acknowledged as soon as practical. Confirmed issues will be addressed in the userscript and documented in a release or repository notice when appropriate.

## Scope

Relevant reports include unsafe DOM handling, unintended access to page data, dependency-loading risks, and behavior that could expose NotebookLM content. General NotebookLM, Tampermonkey, browser, or KaTeX vulnerabilities should be reported to their respective maintainers unless this userscript introduces or amplifies the issue.
